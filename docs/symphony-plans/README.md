# Symphony Plans

This directory contains reusable fan-out planning artifacts and committed plans
created by seed planning tickets.

- [`fan-out-plan-schema.md`](./fan-out-plan-schema.md) - informal schema for
  fan-out plans.
- [`fan-out-criteria.md`](./fan-out-criteria.md) - split criteria captured for
  the future fan-out skill.

Seed planning tickets do not execute the spawned work. They create committed
plans and define follow-up tickets.
